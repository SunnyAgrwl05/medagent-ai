## 🌟 Overview

MedAgent AI is a production-ready healthcare platform built around **five specialized AI agents**, powered by **Gemini 2.5 Flash** with automatic **OpenRouter fallback** and pooled **ElevenLabs** voice — wrapped in a premium, animated Next.js 15 interface.

Real streaming chat. PDF and image report analysis. Medicine identification from a photo. Full-duplex voice conversation. A health history summarizer that ties it all together.

## 🧠 Reliability architecture

Nothing about this is visible to the user — the chat just keeps streaming, even when a key or provider hits a limit.

```
                     ┌──────────────────────┐
      user message   │   POST /api/chat     │
     ───────────────▶│  (streams response)  │
                     └───────────┬──────────┘
                                 │
                                 ▼
                     ┌──────────────────────┐
                     │   lib/ai-router.ts    │
                     └───────────┬──────────┘
                                 │
              ┌──────────────────┴──────────────────┐
              ▼                                      ▼
   ┌────────────────────────┐          ┌────────────────────────┐
   │   Gemini key pool (×5)  │  all 5   │       OpenRouter        │
   │  auto-rotates on 429 /  │  fail ──▶│    automatic fallback   │
   │  quota / 5xx errors     │          │   same prompt, no UI    │
   └────────────────────────┘          │        changes           │
                                        └────────────────────────┘
```

| Layer | Behavior |
|---|---|
| **Gemini pool** | 5 keys, tried in order; rotates on rate limits, quota errors, or transient 5xx — returns on first success |
| **OpenRouter fallback** | Kicks in automatically only if *every* Gemini key fails; frontend never knows the provider changed |
| **ElevenLabs pool** | 4 keys, rotates on auth/quota/credit errors; if all fail, fails *gracefully* so the browser's speech synthesis takes over |
| **Logging** | Every rotation/failover step is logged in development (`Using Gemini Key 2`, `Switching to Key 3`, `All Gemini keys exhausted`, `Using OpenRouter`) — silent in production |

## 🚀 Getting started

### 1 · Prerequisites

- Node.js 18.18+ (Node 20 LTS recommended)
- A [Clerk](https://clerk.com/) application
- A [Supabase](https://supabase.com/) project
- One or more [Google AI Studio](https://aistudio.google.com/) Gemini API keys
- *(Recommended)* An [OpenRouter](https://openrouter.ai/) API key for fallback
- *(Optional)* [ElevenLabs](https://elevenlabs.io/) API key(s) — falls back to the browser's built-in voice if unset

### 2 · Clone & install

```bash
git clone https://github.com/SunnyAgrwl05/medagent-ai.git
cd medagent-ai
npm install
```

### 3 · Configure environment variables

```bash
cp .env.example .env.local
```

> 💡 You only need **one** Gemini key to run the app — extra keys just widen the rotation pool for higher throughput and better resilience against rate limits.

### 4 · Set up Supabase

Open the Supabase SQL editor and run the schema documented at the bottom of `lib/supabase.ts` — it creates `conversations`, `messages`, `activity_log`, and `health_stats` tables with row-level security scoped to the Clerk `user_id`.

### 5 · Run the dev server

```bash
npm run dev
```

Visit **http://localhost:3000** 🎉

### 6 · Build & start production

```bash
npm run build
npm run start
```

## ☁️ Deploying to Vercel

1. Push this repository to GitHub / GitLab / Bitbucket.
2. Go to [vercel.com/new](https://vercel.com/new) and import the repo.
3. Vercel auto-detects Next.js — `vercel.json` is already included.
4. Add every variable from `.env.example` under **Project Settings → Environment Variables**.
5. Deploy. Every push to `main` redeploys automatically.

```bash
npm install -g vercel
vercel
vercel --prod
```

## 🔐 Security notes

- All `/dashboard` and `/api` routes (except webhooks) are protected by Clerk's `clerkMiddleware` — unauthenticated requests are redirected/401'd.
- Supabase access uses the service role key only in server-side API routes; the browser client uses the anon key and relies on RLS policies.
- All AI provider keys (Gemini, OpenRouter, ElevenLabs) are used **server-side only** — never exposed to the browser.
- Never commit `.env.local` — it's already in `.gitignore`. If a key is ever exposed (screenshots, screen shares, commits), rotate it immediately in the provider's dashboard.

## 🩺 Agent design

Each agent has a dedicated, tightly-scoped system prompt in `lib/gemini.ts`, keeping responses on-task and safety-conscious — cautious language, no false certainty, clear disclaimers, and emergency escalation for red-flag symptoms. The same prompt powers the OpenRouter fallback path, so tone and safety behavior stay consistent no matter which provider answers.
